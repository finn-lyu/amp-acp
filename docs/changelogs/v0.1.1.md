# v0.1.1

Follow-up release focused on Zed integration, session continuity, usage visibility, and safer permissions.

## Highlights

- Persisted ACP sessions with replay support for assistant text, thinking blocks, and tool calls.
- Added adapter slash commands: `/export`, `/resume`, `/usage`, `/permissions`, and `/thinking`.
- Added a Thinking on/off session selector, also available as `/thinking on|off`.
- Improved `/usage` with latest-turn token data, restored-session hydration, and `amp usage` account output.
- Rendered Bash tool output in Zed's expandable terminal-style tool cards.
- Added formatted tool titles, tool kinds, file locations, and diff content for richer ACP tool display.
- Added delegated permission prompts through Amp's `delegate` policy and an `amp-acp` helper.
- Capped session log growth and abort active Amp runs during adapter shutdown.
- Added Amp env passthrough for system prompt, toolbox, skills, settings file, log file, and log level.

## Testing

- Expanded unit and binary coverage for session replay, slash commands, usage reporting, tool rendering, permission delegation, shutdown handling, and Amp option construction.
