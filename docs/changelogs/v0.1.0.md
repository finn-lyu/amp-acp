# v0.1.0

Initial fork release of `amp-acp` on the new Amp Code SDK.

## Highlights

- Migrated from deprecated `@sourcegraph/amp-*` packages to `@ampcode/sdk` and `@ampcode/cli`.
- Added Amp mode support for Smart, Rush, and Deep, with Smart as the default.
- Noted that Amp Free is not exposed through the Amp Code SDK. It is a known [limitation](https://ampcode.com/manual/sdk#limitations)
- Enabled thinking by default; set `AMP_ACP_THINKING=false` to disable it.
- Preserved Amp's permission defaults, with `AMP_ACP_DANGEROUSLY_ALLOW_ALL=true` as an explicit opt-in bypass.
- Fixed packaged CLI resolution so the SDK can launch the native Amp CLI binary reliably.

## Testing

- Added coverage for mode advertisement, mode validation, SDK option construction, and binary startup behavior.
